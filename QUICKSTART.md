## 🖥️ How to View the Website

### Option 1: Direct File Opening
```bash
# Simply open the file in your browser
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

### Option 2: Local Server (Recommended)
```bash
# Using Python 3
python3 -m http.server 8000

# Then visit: http://localhost:8000
```

### Option 3: VS Code Live Server
1. Install "Live Server" extension in VS Code
2. Right-click on `index.html`
3. Select "Open with Live Server"

## 🎨 Customization Guide

### Change Colors
Edit in `styles.css`:
```css
:root {
    --primary-color: #6366f1;    /* Change primary color */
    --secondary-color: #8b5cf6;  /* Change secondary color */
    --accent-color: #ec4899;     /* Change accent color */
}
```

### Update Contact Info
Edit in `index.html` (around line 211):
```html
<p>123 Service Street, Business District</p>
<p>+1 (555) 123-4567</p>
<p>info@awesomeonlineservices.com</p>
```

### Modify Service Details
Edit in `script.js` (lines 1-76):
```javascript
const serviceDetails = {
    'service-name': {
        title: 'Your Service',
        // ... modify details
    }
};
```
